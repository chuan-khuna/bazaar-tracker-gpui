# References

- [UnitySpy](https://github.com/hackf5/unityspy) — .NET library for reading the memory of a running Unity (Mono) game process: walks the Mono runtime's type and object metadata so you can read class fields and static state from outside the game.
- [BazaarDB Tracker (beta, portable)](https://depot.bzdb.network/tracker/releases/BazaarDBTracker-beta-Portable.zip) — existing Windows tracker for The Bazaar from BazaarDB; a self-contained .NET Avalonia desktop app (SQLite storage, Squirrel-style `Update.exe` updater) used as a reference implementation.
